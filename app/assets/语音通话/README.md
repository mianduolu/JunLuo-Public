# 语音通话可替换素材

这个目录放白云小姐语音通话用到的可替换素材。后期如果画了正式素材，优先保持同名替换，代码就不用跟着改。

## 当前素材

- `背景.jpg`：来电和通话界面的全屏背景。
- `头像.png`：头像/主视觉，占位 PNG，可替换。
- `接听按钮.png`：临时接听按钮，占位 PNG，可替换。
- `挂断按钮.png`：临时挂断按钮，占位 PNG，可替换。
- `铃声.wav` / `铃声.mp3`：来电循环铃声，占位音效，可替换。
- `接听.wav` / `接听.mp3`：接听反馈音，占位音效，可替换。
- `挂断.wav` / `挂断.mp3`：挂断反馈音，占位音效，可替换。

## 替换建议

- 按钮建议保持正方形 PNG，透明背景，至少 512x512。
- 头像建议保持正方形 PNG，透明或完整圆形背景都可以。
- 背景建议竖屏比例，尽量保留上方和中间的视觉安全区，避免被状态栏、名字和按钮遮挡。
- 音效可以用 mp3、wav、m4a；App 代码优先接 mp3，也可以改成 wav。
- 铃声建议 1-3 秒，适合循环；接听/挂断音建议 0.2-1 秒。
- 不要把私人音频、API key、voice id 放进这个目录。
