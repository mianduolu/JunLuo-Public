# 背景扩展说明

当前已支持三类背景：随时间变化的天空、固定时间段天空、自定义图片。首页与聊天页会共享用户当前选择的背景。

添加新的背景模式时，负责选择和渲染该背景的模块还需要向 `HomeScreen` 传入 `src/theme/homeReadability.ts` 中定义的 `HomeBackgroundReadability`：

- 当时间文字背后的区域偏深时，使用 `headerText: 'light'`；背景偏浅时，使用 `headerText: 'dark'`。
- 当六宫格功能标签背后的区域偏深时，使用 `exposedLabelText: 'light'`；背景偏浅时，使用 `exposedLabelText: 'dark'`。

天空背景会自动按当前渐变色判断文字深浅。自定义图片当前默认使用浅色文字，用户可以在设置页分别调整顶部时间和首页功能标签的文字颜色；该选择会与背景设置一起保存。

由于现有天气绘制组件同时负责绘制天空底色，自定义图片模式暂不叠加首页天气动画，以避免修改已经封存的动画实现。
